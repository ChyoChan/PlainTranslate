# PlainTranslate｜標誌使用指南

**概念：** P 表示 Plain；留白的 T 表示 Translate。一個清楚輪廓，第二眼才發現字母關係。

**選用版本：** Dock／Finder 用黑底 tile App 圖示；選單列用黑色 template，讓 macOS 自動
反白。網頁及 GitHub 用橫排，較方正的位置用直排；深色底用白色版。`app-icon-dark` 保留為相容別名，
同樣是黑底白標誌；App 不會自動切換 Dock 圖示。

| 色彩 | HEX | RGB | CMYK 約數 |
| --- | --- | --- | --- |
| Black 主色 | `#000000` | 0, 0, 0 | 0, 0, 0, 100 |
| Ink 字標／深色底 | `#000000` | 0, 0, 0 | 0, 0, 0, 100 |
| White 反白 | `#FFFFFF` | 255, 255, 255 | 0, 0, 0, 0 |
| Paper 版面底色 | `#F7F7F7` | 247, 247, 247 | 0, 0, 0, 3 |

白／黑對比 **21:1**；Ink／白 **21:1**。黑色標誌用於淺色底，深色底改用白色版。
CMYK 僅供起稿參考；Pantone 未配對，實體印刷需另作色票校對及打樣。

**留白：** 以 P 直筆寬為 1x（256 單位母稿上的 40 單位），在實際輪廓外保留至少 1x。
App tile 的內部留白已固定，使用現成圖示，不要自行放大填滿 tile。

**最小尺寸：** 獨立符號 16px（用 `symbol-small`）；一般符號 32px；橫排寬 180px；
直排寬 160px；字標寬 140px。更小的位置一律改用獨立符號，不硬縮完整名稱。

**字體：** Logo 字標為原創幾何路徑，已轉成輪廓；毋須任何字型授權或字型檔。
產品內文繼續使用 macOS 系統字型。不要以鍵盤輸入的字體重做 Logo 字標。

**保留幾何：** P 維持等寬直筆與圓弧，T 保持透明。反白符號已略減筆重；小尺寸版已放大
T 的留白。不要拉闊、壓扁、旋轉、填掉 T、加陰影漸層，或重排橫排／直排內的比例。
